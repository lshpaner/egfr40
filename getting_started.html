Getting Started

Score one individual

from egfr40 import egfr40_risk

egfr40_risk(
    age=70, male=1, egfr=40, uacr=150, sbp=140, bp_meds=1,
    hf=0, chd=1, afib=1, smoking="former", bmi=28,
    dm=True, hba1c=7, oral_dm=0, insulin=0,
)
# 0.166  -> a 16.6% 3-year risk

This individual has diabetes and an eGFR below 60, so the function uses the “diabetes, eGFR <60” model. The result matches the online CKD-PC calculator (16.6%).

Score a cohort

from egfr40 import add_egfr40_risk_col

df = add_egfr40_risk_col(df)   # adds an "egfr40_3year" column

See egfr40 quickstart for a worked example with output, Usage Guide for column mapping, and Input Requirements and Common Pitfalls for the expected units and codes.
